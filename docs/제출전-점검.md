## 오늘 바꾼 것

### 1. `DAON_SECRET` 이 기본값이면 배포가 실패한다

`webservice/app.py`. 세션 쿠키 서명 키가 저장소에 적힌 기본값 그대로 배포되면
누구나 남의 로그인 쿠키를 위조할 수 있다. 경고 로그는 아무도 안 읽으므로
**기동 실패**로 냈다 — 전시 서버가 기본 시크릿으로 뜨는 것보다 배포가 실패하는
편이 낫다.

로컬 개발은 그대로 편해야 하므로 배포 신호(`DAON_EMBED=1`)일 때만 막는다.

```bash
DAON_SECRET=$(python3 -c 'import secrets;print(secrets.token_urlsafe(32))')
```

> **배포 전 확인**: 호스팅 대시보드의 환경변수에 `DAON_SECRET` 이 실제 값으로
> 들어 있어야 한다. 없으면 다음 배포가 기동 단계에서 멈춘다(의도된 동작).

### 2. 연결 진단 패널을 프로덕션에서 감춤

`webservice/frontend/src/pages/Live.tsx`. 카메라 없음 화면의 "연결 상태 자세히"
를 펼치면 온라인 관람객에게 이런 문장이 보였다.

> 백엔드가 꺼져 있습니다. uvicorn 이 8000 포트에서 도는지 확인하세요.
> python3 main.py 0 --no-serial --live-url http://localhost:8000

관람객에게는 의미가 없고, 잘 만든 체험이 갑자기 미완성처럼 보인다. 개발 서버
(`npm run dev`)나 `?diag=1` 을 붙였을 때만 나오게 했다 — 부스 노트북에서
배포 빌드를 그대로 쓰면서 진단이 필요할 때가 있어 뒷문은 남겼다.

### 3. 캐시의 진짜 이음매를 테스트로 덮음

`tests/test_sample_pipeline.py` (신규 6건).

기존 라우트 테스트는 `_lookup_cache` 를 통째로 monkeypatch 해서, **매니페스트
파일을 실제로 읽는 경로가 한 번도 실행되지 않았다.** `build_samples.py` 가 쓰는
형식과 `cache.lookup` 이 읽는 형식이 어긋나도 전부 통과했다는 뜻이다. 샘플
영상이 완성되는 날 그 어긋남을 처음 발견하면 늦다.

이제 스크립트가 만든 진짜 매니페스트를 놓고 업로드까지 태운다. YOLO 만 대역이고
해시 계산·매니페스트 입출력·라우트 조회는 실제 코드다. 덮은 것:

- `build_samples.py` 가 쓴 매니페스트를 `cache.lookup` 이 읽을 수 있다
- 파일명을 바꿔 올려도 내용이 같으면 캐시가 걸린다
- 영상을 다시 만들면 해시가 달라져 캐시를 비껴간다 (재실행이 필요하다는 신호)
- 캐시 적중이면 폴링 없이 즉시 `done`, 리포트 이미지까지 서빙된다
- 캐시 적중 시 업로드 원본을 지운다 (전시 중 디스크가 새지 않게)
- **샘플이 아직 없어도 서비스는 평소대로 돈다** ← 지금 배포된 서버의 상태

### 4. 영상 길이 상한 테스트

`tests/test_frame_limits.py` (신규 4건). `DAON_ANALYZE_MAX_SECONDS` 는 값만
있고 실제로 끊기는지 확인하는 테스트가 없었다. 샘플링 로직을 손볼 때 조용히
무력화되는 종류의 방어라 고정해 뒀다.

### 5. `tsconfig.json` 에 `vite/client` 타입 추가

`import.meta.env` 가 `tsc --noEmit` 에서 TS2339 로 걸렸다.

## 남은 것

### 은서님 차례

| 항목 | 왜 막혀 있나 |
|---|---|
| **AI 할머니 영상 3개** (안방/거실/부엌) | 파일이 있어야 사전 계산을 돌린다 |
| 실시간 감지 데모 영상 | `/live` 가 지금은 "준비 중" 안내로 대체 중 |
| 배포 환경변수에 `DAON_SECRET` 설정 | 없으면 다음 배포가 기동에서 멈춘다 |

영상이 나오면:

```bash
# 1) public/samples/ 에 bedroom.mp4 / living.mp4 / kitchen.mp4 로 넣고
# 2) 사전 계산
python3 scripts/build_samples.py --auto
# 3) 프런트 재빌드 후 배포
cd webservice/frontend && npm run build
```

`webservice/consulting/samples/manifest.json` 이 만들어지면 그때부터 샘플
업로드는 분석 없이 즉시 응답한다. **영상을 다시 만들면 해시가 바뀌므로
`build_samples.py` 를 다시 돌려야 한다.**

- [ ] iOS Safari · Android Chrome 실기기에서 레이아웃과 영상 재생
- [ ] 서버 재시작 후 지난 리포트가 남아 있는지 (호스팅에 볼륨이 붙어 있는지)

`iframe_test.html` 로 첫 번째 항목을 로컬에서 흉내 낼 수 있다.

### 배포 URL 자동 점검

URL 이 정해지면 이것만 돌리면 위 표의 "배포" 칸이 한 번에 채워진다.

```bash
python3 scripts/smoke_deploy.py https://내주소
```

HTTPS · CSP `frame-ancestors` · `X-Frame-Options` 부재 · `SameSite=None; Secure`
쿠키 · SPA 딥링크 · 샘플 영상 존재 여부 · 캐시 응답 시간 · 업로드 제한 ·
동시 요청을 순서대로 확인하고, 실패가 있으면 종료 코드 1 을 낸다.

## 참고: 부하 관련 환경변수

| 변수 | 기본값 | 뜻 |
|---|---|---|
| `DAON_MAX_UPLOAD_MB` | 200 | 업로드 상한. 초과 시 413 |
| `DAON_MAX_CONCURRENT_JOBS` | 2 | 동시에 도는 분석 수 (세마포어) |
| `DAON_MAX_INFLIGHT_JOBS` | 8 | 대기 포함 총량. 초과 시 503 |
| `DAON_ANALYZE_MAX_SECONDS` | 90 | 영상 앞부분만 분석하는 상한 |
| `DAON_ANALYZE_FPS` | 3 | 초당 샘플링 프레임 수 |
| `DAON_EMBED` | 0 | 1이면 iframe 배포 모드 (HTTPS·SameSite=None 필수) |
| `DAON_FRAME_ANCESTORS` | `*` | 전시 사이트 도메인이 정해지면 좁힐 것 |
