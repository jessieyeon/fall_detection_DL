# 시연 카메라 구도 (고정)

이 구도에서 데이터를 모으고, 이 구도로 시연한다. **바꾸면 다시 찍어야 한다.**

지도교수 제안 중 "시연 환경이나 카메라 구도를 미리 설정해놓고 해당 셋팅에서
데이터셋 모아서 학습" 쪽을 택했다. 짧은 시간에 구도 무관 강건성을 확보하는 것보다
확실하기 때문이다. 대신 **구도를 재현할 수 없으면 이 선택은 통째로 무의미해진다** —
그래서 숫자로 적어 둔다.

## 확인 방법 — 이것만은 반드시

**체험자가 똑바로 섰을 때 머리 끝과 발끝이 모두 화면 안에 들어와야 한다.**

발이 잘리면 `hip_h`(발목 기준 엉덩이 높이)가 계산되지 않는다. 이 특징이
'앉기 vs 낙상'을 가르는 핵심이라, 발이 안 보이면 v6 정규화의 절반이 죽는다.

확인은 이렇게 한다:

```bash
python3 scripts/list_cameras.py
```

```bash
python3 main.py <카메라번호> --no-serial
```

화면에 그려지는 스켈레톤에서 **발목 점(27, 28)이 보이는지** 확인한다.
안 보이면 카메라를 뒤로 물리거나 높이를 낮춘다.

## 촬영 목록

각 5~10초. 사람은 최소 2명(p1, p2). 파일명 규칙을 지켜야 라벨 작업이 없다 —
`extract_v6.py` 는 `ONSETS` 에 없는 클립을 전부 정상(negative)으로 처리한다.

### 낙상 클립을 추가로 찍는다면

낙상은 **`ONSETS` 에 시작 시각(초)을 손으로 적어야** 라벨이 붙는다.
`model_training/extract_v6.py` 의 `ONSETS` 딕셔너리에 추가한다:

```python
          "fall_p1_forward_03": 2.10,      # 넘어지기 시작하는 시각(초)
```

시각은 영상을 재생해 **몸이 무너지기 시작하는 순간**으로 잡는다.
안전 문제도 있으니 매트 위에서만, 무리하지 말 것.
