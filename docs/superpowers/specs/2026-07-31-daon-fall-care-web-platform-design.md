# 다온(Daon) 낙상 케어 웹 플랫폼 — 설계 문서

- 작성일: 2026-07-31
- 성격: **데모용 MVP** (졸업작품/공모전 시연). 시연에서 실제로 돌아가 보이는 것이 최우선.
  어려운 연동은 목업/사전수집으로 처리하되, 화면상으로는 진짜처럼 보이게 한다.
- 기존 저장소(`fall_detection_DL`)의 CV 파이프라인·모바일 뷰어 위에 웹 서비스 계층을 얹는다.

## 1. 목표와 범위

낙상 위험 어르신과 보호자를 위한 웹 서비스. 3개 기능으로 구성한다.

1. **컨설팅** — 집 안 생활 영상을 업로드하면 낙상 위험도를 분석해 **히트맵 이미지 + 줄글 리포트**를 준다.
2. **실시간 중계** — 맥북 카메라의 실시간 낙상 감지 결과(스켈레톤·타일)를 폰 브라우저로 중계한다. (기존 자산 재사용)
3. **마이페이지** — 로그인, 낙상 위험 자가진단 설문, 보호자 매칭, 주소→평면도/근처 병원.

### 1.1 진짜 구현 / 목업 경계 (데모 MVP)

| 기능 | 진짜로 구현 | 목업 · 사전수집 |
|---|---|---|
| ① 컨설팅 | YOLO11 체류 히트맵 실제 생성 + 규칙 기반 리포트 | 업로드 영상은 시연용 샘플, 결과 사전 캐시 |
| ② 실시간 중계 | 기존 WebSocket 파이프라인 실제 연동 | — (이미 동작) |
| ③ 마이페이지 | 로그인/세션, 설문 저장·채점, 6자리 코드 페어링, 보호자 열람, **근처 병원(카카오 API)** | **주소→평면도**는 사전수집 이미지 매칭(겉보기 자동), 낙상 **알림은 보호자 페이지 이벤트 표시만** |

### 1.2 명시적 비목표 (Non-goals)

- 실제 아파트 평면도 자동 크롤링/공식 API 연동 (민간 독점 데이터·소유자 동의 문제로 제외).
- Telegram 등 실제 푸시 알림 (보호자 페이지 내 이벤트 표시로 대체).
- OAuth·이메일 인증·비밀번호 재설정.
- 컨설팅 분석의 딥러닝 재학습 (히트맵은 기성 YOLO11, 해석은 규칙 기반).
- 다국어·접근성 고급 대응(기본 시맨틱 마크업 수준만 유지).

## 2. 아키텍처

```
[React SPA]  ──HTTP/JSON──>  [FastAPI]  ──>  SQLite
  /consulting                   │             (users, guardian_links, pairing_codes,
  /live                         │              surveys, reports)
  /mypage                       ├── /api/consulting/*  업로드→분석 작업→리포트
                                ├── /api/mypage/*      로그인·설문·보호자·주소/병원
                                ├── /ws                실시간 스켈레톤/타일 중계 (기존 재사용)
                                └── 외부: 카카오 로컬 API (근처 병원)

[기존 CV 파이프라인]  main.py / pose_source.py / tiles.py / tile_protocol.py
  - 실시간 낙상 감지 + 아두이노 타일 제어. 그대로 유지.
  - 실시간 감지 결과를 FastAPI /ws 로 push (기존 webapp_server 로직 이관/재사용).
```

- **백엔드**: 파이썬/FastAPI (분석 코드가 전부 파이썬이므로 자연스러움. Node 미도입).
- **프런트**: React SPA (Figma 디자인 자산 활용). FastAPI가 빌드 산출물을 정적 서빙(시연) 또는 개발 시 Vite dev 서버.
- **DB**: SQLite (단일 파일, 시연에 충분). 현재 비어 있는 `database.py`를 실제 스키마로 채운다.
- **분리 원칙**: 실시간 감지 파이프라인은 웹서버가 죽어도 독립적으로 동작한다(기존 원칙 유지).

## 3. 기능 ① 컨설팅

### 3.1 분석 흐름

1. 사용자가 영상 업로드(또는 시연용 샘플 선택).
2. 백엔드가 **YOLO11 + BoT-SORT로 사람 추적**, 프레임마다 바운딩박스를 가우시안 블러 마스크로 누적해 **체류/이동 히트맵** 생성 → 격자(예: 80px) 점수화. (친구 노트북 `Team_New_Gen_Bindex` 로직 이식)
3. **규칙 엔진**(`rules.py`)이 히트맵 패턴을 낙상 위험 소견으로 번역:
   - 오래 머무는 지점(고체류) → 의자/침대 주변 안전 점검 권고
   - 좁은 통과 동선(고빈도 이동 + 협소) → 장애물 제거·조명 권고
   - 화장실/현관 왕복 동선 → 미끄럼 매트·손잡이 권고
   - 각 패턴에 매칭된 **템플릿 문장**으로 리포트 생성.
4. 렌더: **히트맵 이미지를 사전수집 평면도 위에 오버레이** + 줄글 리포트.
5. `reports`에 저장 → 마이페이지 표시 → 연결된 보호자도 열람.

### 3.2 처리 방식

- YOLO는 무겁다 → **백그라운드 작업 + 상태 폴링**. 업로드 시 job 생성, React가 "분석 중…" 표시 후 완료되면 결과 로드.
- 시연용 샘플은 결과를 **미리 캐시**해 즉시 뜨게 한다(시연 안정성).

### 3.3 재사용 판단

- **쓰는 것**: 노트북 ①의 YOLO11 추적 + 히트맵 누적 + 격자 점수화. "최적 위치 추천" 로직을 "최적 안전장치 위치"로 전용.
- **안 쓰는 것**: 노트북 ②(참고자료)의 CNN 분류 — 라벨이 순환적이라(히트값>0 → 클래스1) 학습 가치 없음. 서술만 참고.
- **의존성 주의**: `ultralytics`(+torch)는 수백 MB. 업로드 영상에 오프라인으로 1회 실행하는 용도이므로 데모엔 무방하나, 실시간 감지(MediaPipe)와는 별개의 두 번째 CV 스택이다.

## 4. 기능 ② 실시간 중계

- 기존 `webapp_server.py`의 WebSocket 브로드캐스트(포즈 스켈레톤·타일 발사 이벤트)를 **재사용/이관**한다.
- `main.py` 파이프라인이 감지 결과를 `/ws`로 push, React `/live` 라우트가 구독해 스켈레톤·2×2 타일을 렌더.
- 영상 자체는 전송하지 않고 관절 좌표(작은 JSON)만 보낸다(기존 설계 유지).
- 신규 구현 최소. 기존 뷰어(`webapp/index.html`)의 렌더 로직을 React 컴포넌트로 이식.

## 5. 기능 ③ 마이페이지

### 5.1 계정 모델

- 역할 2개: `어르신`(모니터링 대상) / `보호자`. `users.role` 한 필드로 구분.
- 시연용 계정 시드: 어르신 1, 보호자 1.

### 5.2 로그인

- **이메일 + 비밀번호 + 세션 쿠키**. OAuth·이메일 인증 없음.
- 비밀번호는 **stdlib `hashlib.pbkdf2_hmac`로 salt+해시** 저장(평문 저장 금지 — 데모여도 지킴). bcrypt 의존성 미도입.

### 5.3 설문조사 — 낙상 위험 자가진단

- 질문 8~10개를 **`questions.json` 설정**으로 관리(나이대, 과거 낙상 경험, 복용 약, 어지럼증, 보행보조기 사용, 야간 화장실 빈도 등). 코드에 하드코딩하지 않음.
- 규칙 기반 가중 점수 → **위험 등급(낮음/보통/높음)** 산출·저장.
- 마이페이지에 표시, 연결된 보호자도 열람.

### 5.4 보호자 매칭 — 6자리 페어링 코드

- 어르신이 **6자리 코드 생성**(`pairing_codes`, 만료 있음) → 보호자가 입력 → `guardian_links`에 연결.
- 연결 후 보호자 마이페이지에서 어르신의 **① 자가진단 등급 + ② 컨설팅 리포트 + ③ 실시간 상태**를 열람.
- 낙상 이벤트는 **보호자 페이지에 이벤트로 표시만**(실제 푸시/Telegram 없음).

### 5.5 주소 → 평면도 / 근처 병원

- **평면도**: 시연 아파트 1~2개의 평면도 이미지를 **사전수집**(`data/floorplans/`), 아파트명으로 매칭해 표시. 화면상 "아파트명 입력 → 평면도 자동 등장". 컨설팅 히트맵의 배경으로 사용.
- **근처 병원**: **카카오 로컬 API**(무료, 일 10만 호출)로 주소 좌표 근처 병원(`HP8`)·약국(`PM9`) 실검색. REST API 키 필요.

## 7. 테스트 (기존 pytest 스타일 유지)

- **단위 테스트 O (순수 함수)**:
  - `rules.py`: 대표 히트맵 패턴 입력 → 기대 발견사항/권고 출력.
  - `survey.py`: 대표 응답 → 기대 점수·등급.
  - 기존 `tests/test_tiles.py`와 동일한 무의존성 테스트 결.
- **단위 테스트 X**: YOLO·MediaPipe 자체(무거움) → 시연 샘플 영상 실행으로 확인.
