## A. 고령자 의료비 — "지출은 이미 여기서 발생하고 있다"

출처: **국민건강보험공단·건강보험심사평가원, 『2024년 건강보험 통계 연보』(2025.11.28 공동 발간)**

| 항목 | 수치 |
|---|---|
| 2024년 전체 건강보험 진료비 | 116조 2,375억원 (전년 대비 +4.9%) |
| 65세 이상 노인 진료비 | **52조 1,935억원** (전년 대비 +6.7%) |
| 2020년 노인 진료비 | 37조 6,135억원 → **4년간 +38.8%** |
| 건강보험 적용인구 중 노인 비중 | 18.9% |
| 전체 진료비 중 노인 진료비 비중 | **44.9%** |
| 노인 1인당 연평균 진료비 | **550만 8,000원** |
| 전체 평균 1인당 진료비 | 226만 1,000원 (노인이 **2.4배**) |

> 인용 예시: "인구의 18.9%에 불과한 65세 이상 고령층이 전체 건강보험 진료비의 44.9%인 52조 1,935억원을 사용하고 있다(건강보험공단·심평원, 2024년 건강보험 통계 연보)."

## B. 낙상의 비중과 발생 장소 — "실내 바닥이 문제다"

출처: **공정거래위원회·한국소비자원·농촌진흥청, 고령자 낙상사고 안전주의보(2022.08.30)** / 소비자위해감시시스템(CISS) 2018~2021년 접수 기준

| 항목 | 수치 |
|---|---|
| 최근 4년간(2018~2021) 고령자 안전사고 | 총 23,561건 |
| 그중 낙상사고 | **14,778건 (62.7%)** |
| 낙상 발생 장소 1위 — 주택 | **11,055건 (낙상의 74.8%)** |
| 최다 연령대 | 75~79세 (3,248건) |
| 손상 부위 1위 | 머리 및 뇌(뇌막) 3,014건 |
| 연령 증가에 따른 변화 | 손목 골절 < 둔부(고관절) 골절 비중 증가 |

> 이 표의 핵심: 고령자 안전사고의 **10건 중 6건이 낙상**이고, 그 낙상의 **4건 중 3건이 집 안에서** 발생한다. 실내 바닥 타일이라는 접근의 정당성이 여기서 나온다.

참고: 인구 10만 명당 안전사고 발생빈도는 65세 이상이 5.08건으로 전 연령대 중 최고.

## C. 낙상 → 고관절 골절 → 장기요양 진입 — "비용이 장기화되는 경로"

출처: **대한정형외과학회지 2023;58(5):402, 「고령의 고관절 골절 환자의 노인장기요양 서비스 현황 분석」**

| 항목 | 수치 |
|---|---|
| 분석 대상 고관절 골절 환자 | 80,675명 |
| 노인장기요양 서비스 신청자 | 14,795명 (**18.3%**) |
| 장기요양 인정자 | 11,020명 (**13.7%**) |
| 신청자 대비 인정률 | 74.7% |
| 인정자의 이용 형태 | 재가 54.3% / 시설 25.9% / 비수급 19.8% |

사망률(국내 peer-reviewed 연구 기준):

- 65세 이상 고관절 골절 환자 수술 후 1년 내 사망률 **15.8%**
- 다른 국내 연구에서는 **10.7%**
- 80세 이상, 기저질환이 많을수록 유의하게 상승

> 논리 구조: 낙상 1건은 단발성 치료비로 끝나지 않는다. 고관절 골절 환자 **6명 중 1명 이상이 장기요양 서비스를 신청**하고, 그중 상당수가 수년 단위의 요양급여 대상이 된다. 즉 낙상 예방은 급성기 의료비가 아니라 **장기 요양 비용의 유입 자체를 차단**하는 개입이다.

## D. 삼성생명의 시니어 시장 투자 — "지출 절감이 아니라 사업 적합성"

출처: **금융감독원 전자공시시스템(DART) 2025.9.30 공시**, 헤럴드경제 2025.10.01 보도

| 항목 | 수치 |
|---|---|
| 삼성노블라이프 설립 | 2025년 8월 초, 삼성생명 100억원 출자 · 지분 100% |
| 추가 출자 총액 | **4,535억원** (2025.9.30 공시) |
| ├ 유상증자 (보통주 인수) | 310억원 |
| └ 현물출자 (노블카운티 토지·건물 일체) | 4,225억원 |
| 이사회 의결일 | 2025.9.25 |
| 출자 후 노블라이프 자본금 | 4,635억원 |

경쟁사 동향 (같은 기사):

- KB라이프 → KB골든라이프케어 유상증자 500억원 (2025.6), 광교 프리미엄 요양시설 개소 (2025.9.15)
- 신한라이프 → 신한라이프케어 유상증자 250억원
- 하나생명 → 하나더넥스트라이프케어 설립, 자본금 300억원 (2025.6)

> 활용 포인트: 삼성생명은 이미 요양시설을 **직접 운영**하는 사업자다. 낙상 예방 시스템은 (1) 보험금 지급 감소, (2) 노블카운티 등 자사 운영 시설의 안전 경쟁력, (3) 보장-서비스 일체형 솔루션의 기술 축 — 세 방향에서 동시에 기여한다. 서론은 "비용을 줄여드립니다"가 아니라 "이미 하고 계신 사업의 빠진 조각입니다" 프레임으로 가는 것이 유리.

## E. 쓰면 안 되는 수치 (검증 결과 부적절)

| 유통되는 표현 | 문제 |
|---|---|
| "국내에서 낙상으로 사망하는 65세 이상 노인 연간 83만 명" | **국내 수치 아님.** 한국 연간 총사망자가 약 35만 명이라 성립 불가. WHO의 전 세계 추정치가 국내 통계처럼 잘못 인용된 것으로 보임. |
| "고관절 골절 방치 시 2년 내 사망률 70%" | 언론·병원 홍보 자료에서 반복되나 국내 peer-reviewed 근거 불명확. 대신 검증된 **1년 사망률 10.7~15.8%** 사용 권장. |
| "삼성생명의 노인 대상 연간 지출액 O조원" | **공개 자료 없음.** 연령대별 지급보험금은 IR·감사보고서에 분리 공시되지 않음. 추정치를 단정적으로 쓰면 안 됨. |

## 서론 구성 제안 (3단 논리)

1. **문제의 규모** — A: 노인 진료비 52조원, 전체의 44.9%. 고령화 속도상 계속 증가.
2. **문제의 위치** — B: 그 손상의 62.7%가 낙상이고, 낙상의 74.8%가 집 안에서 발생. 병원이 아니라 **거실과 욕실 바닥**에서 결정된다.
3. **개입의 가치** — C+D: 낙상 1건 예방은 급성기 치료비가 아니라 장기요양 진입(고관절 골절 환자의 18.3%가 신청)을 막는 것. 그리고 이 개입은 삼성생명이 4,535억원을 투자한 시니어케어 사업의 예방 단계와 정확히 맞물린다.
